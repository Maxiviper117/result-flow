# Finalization and output

| Method | Purpose |
| --- | --- |
| `match` | Handle exactly one active payload |
| `unwrap` | Return a value or throw the failure |
| `unwrapOr` | Return a value or eager default |

`Output\LegacyOutput`, `Output\DebugOutput`, and `Laravel\LegacyResponse` are explicit adapters. See [boundary reference](/reference/boundaries).
